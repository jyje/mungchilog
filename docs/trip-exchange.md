# 여행 파일 내보내기와 불러오기

뭉치로그는 여행 하나를 하나의 `.mungchilog.json` 파일로 내보내고, 인터넷이 없는 곳에서도 다시 불러올 수 있습니다. JSON 단일 파일은 일정, 스팟, 체크리스트, 저장한 동선 선호도와 현재 Base64 대표 이미지를 함께 보관합니다.

## 안전한 동작

- 내보내기 파일에는 여행 ID, 구성원, 초대, 소유자, 현재 사용자 역할, 로그인 정보가 없습니다.
- 파일을 불러오면 항상 현재 계정의 새 여행 복사본을 만듭니다. 원본이나 공유 여행을 덮어쓰지 않습니다.
- 포맷 버전을 검사합니다. 지원하지 않는 버전이나 손상된 데이터는 저장하기 전에 거절합니다.
- 현재 대표 이미지는 Base64로 포함되므로 전체 파일은 3 MiB 이하여야 합니다. 객체 저장소 전환 전의 한시적 제한입니다. 관련 후속 작업은 [#9](https://github.com/jyje/mungchilog/issues/9)에서 관리합니다.

## 파일 형식 v1

```json
{
  "format": "mungchilog.trip",
  "version": 1,
  "exportedAt": "2026-08-29T00:00:00.000Z",
  "trip": {
    "title": "파리 주말",
    "timezone": "Europe/Paris",
    "currency": "EUR",
    "startDate": "2026-10-01",
    "endDate": "2026-10-03",
    "days": []
  }
}
```

기존의 일정 JSON을 붙여넣는 방식도 호환을 위해 유지합니다. 단, 여기에서도 `id`는 무시되어 새 여행으로 불러옵니다.

## 시간대

새 여행에서 대표 장소를 선택하면 서버가 장소 좌표로 IANA 시간대를 찾아 설정합니다. Time Zone API가 꺼져 있거나 오프라인인 경우, 또는 시간대를 비워 둔 JSON을 불러오는 경우에는 항상 `Asia/Seoul`을 사용합니다. 사용자는 생성 화면에서 이를 직접 바꿀 수 있으며, 직접 고른 값은 자동 조회가 덮어쓰지 않습니다.
